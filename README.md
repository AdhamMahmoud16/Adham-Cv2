# Adham CV - Responsive component library

Built with the methods from the CSS Layout & Styling guide:
- Flexbox navbar and wrapping tags
- CSS Grid, mobile-first: 1 column, 2 columns (600px+), 3 columns (1024px+)
- CSS variables on :root (--primary, --radius, --space, ...)
- Components: buttons, cards, table, form elements, alerts, CSS-only modal (:target)
- Dark mode by redefining variables in @media (prefers-color-scheme: dark)

Pages: index.html, about.html, blogs.html, components.html, contact.html
